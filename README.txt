==========================================

الملفات (كلها مسطحة بدون مجلدات):
---------------------------------
index.html          الصفحة الرئيسية
products.html       صفحة جميع المنتجات + فلترة
cart.html           السلة + ثلاث خيارات دفع
account.html        حسابي + الطلبات
seller.html         لوحة البائع (رفع المنتجات + موافقة الشروط)
terms.html          الشروط والأحكام كاملة
style.css           التصميم
app.js              المنطق الكامل
firebase-config.js  إعدادات Google Auth + Firestore
firestore.rules     قواعد الحماية
shurak-banner.jpg   البنر
README.txt          هذا الملف

ما تم تنفيذه حسب طلبك:
-----------------------
✓ ثلاث خيارات دفع في السلة:
  1. الدفع عند الاستلام
  2. تحويل بنكي
  3. دفع إلكتروني لاحقاً

✓ ربط Google Auth (Firebase)
  - جاهز 100% 
  - حالياً يعمل في وضع تجريبي حتى تضع مفاتيح Firebase

✓ كل صفحة لحالها (ليست صفحة واحدة):
  - الرئيسية / المنتجات / السلة / حسابي / البائع / الشروط

✓ المنتجات ينزلها التاجر بنفسه من صفحة seller.html
  - مع إلزام الموافقة على الشروط والأحكام قبل النشر

✓ شروط وأحكام كاملة باللغة العربية

✓ بيانات تجريبية واقعية (10 منتجات بأسماء بائعين)

طريقة التشغيل:
--------------
1. فك الضغط
2. افتح index.html في المتصفح
   أو شغّل: python -m http.server 8080

لربط Google الحقيقي:
--------------------
1. ادخل console.firebase.google.com
2. أنشئ مشروع → Authentication → Google → تفعيل
3. انسخ الإعدادات إلى firebase-config.js
4. أضف localhost في Authorized domains

ملاحظات:
---------
- المنتجات والسلة والطلبات محفوظة حالياً في localStorage
- عند ربط Firebase تنتقل تلقائياً إلى Firestore
- البائع يستطيع حذف منتجاته
- عند تأكيد الطلب يُحفظ في سجل الطلبات داخل حسابي
